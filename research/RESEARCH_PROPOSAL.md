# RAMORT research proposal

Can RAMORT infer useful symbolic cost bounds across Rust loops, recursive calls, and mutable borrows while showing exactly which facts justify each result? The first target is a deterministic, safe Rust subset with explicit collection summaries. A two-stack queue is a useful starting point. One pop can transfer the entire back stack, yet a sequence of operations from an empty queue can have constant amortized work per operation. The distinction depends on the metric, initial credit, and summary assumptions.

## Proposed cost semantics and bound language

Give each modeled MIR edge a guard, state update, and metric-specific charge. Start with one tick per designated operation. Add allocation counts or bytes copied only after defining the corresponding events. Length, capacity, and live bytes have different units. Peak live bytes require a maximum over live storage along a trace. Record target word width, overflow behavior, panic/unwind coverage, and preconditions for each library call. A translation into mathematical integers requires range proofs or explicit machine arithmetic.

For each covered finite execution prefix starting in state s₀, let C be the sum of its tick charges. A proposed budget B(x), where x measures the entry state, asserts C ≤ B(x) under the recorded preconditions. Prove termination separately when claiming total runtime. An amortized step with allowance a must satisfy c + Φ(s′) ≤ a + Φ(s). Summing steps cancels intermediate credits. Nonnegative final potential bounds total actual cost by the initial potential plus the sum of allowances. With unit-cost stack operations, moving b items costs 2b ticks and reduces a back-stack potential of 2b to zero.

Keep the affine solver language. Give reportable bounds a typed expression tree with named entry sizes, constants, sums, products, maxima, and guarded ceiling-log terms. Track unknowns explicitly. Bind each variable to an input projection, its domain, and unit. Sequential fragments add costs after substituting output sizes into the successor contract. Alternative paths use guarded bounds or their maximum. Derive a display class such as O(n log n) only after composition.

## Research hypotheses and experiments

1. **Alternating runtime and size inference.** Within each control-flow component, infer local transition counts from ranks and lift them using entry frequencies and entry sizes. Use those counts to bound accumulated updates and feed resulting sizes into later count proofs. For two sequential loops where the first increments k by two n times from zero, the second may execute up to 2n times. For a persistent inner cursor, charge its increments across all outer iterations. Compare precision against current rankings and KoAT on a shared guarded-integer subset. Record unsupported updates and retain only justified facts when inference reaches its budget. See [KoAT and difference constraints](REFERENCES.md#loops-and-recursion).
2. **Polynomial AARA.** For natural sizes n, use Φ(n) = Σ aₖ binom(n,k), extending to products of basis terms over independent sizes under a total degree cap. Pascal's identity reduces a unit size shift to a linear transformation of coefficients. Synthesize nonnegative rational coefficients, then replay transfer and join obligations exactly. Test whether degree two pays for a triangular scan where degree one fails. Compare inference time and witness size at each degree. See [AARA foundations](REFERENCES.md#potentials-and-certificates).
3. **Borrow-aware potentials.** For an exclusive loan, introduce current credit and a prophecy for the credit returned at loan end. Suspend the owner's access to lent credit, account for updates through the borrower, and discharge the prophecy on every return path. Nest these obligations on reborrow. At a join where either of two vectors was selected, preserve alternatives or weaken the guaranteed credit. Test append through a reborrow and a conditional receiver. Combining polynomial templates with these linear RaRust rules needs a preservation proof for the supported fragment. Compare MIR loan facts with Charon LLBC on the same examples. See [RaRust](REFERENCES.md#rust-borrows).
4. **Size-aware recursion.** Collect a guarded recurrence per call-graph component. Sum calls executed on a single path and maximize across exclusive paths. Check the base cost, strict descent, and argument sizes at each site. A balanced split with linear local work admits O(n log n) when both child sizes are bounded by half up to rounding. Quicksort permits a split of 0 and n−1, which requires a separate worst-case argument. Attempt mutual recursion only with a common well-founded measure or a checked tuple of measures.
5. **Resource decomposition.** Track a component such as maximum recursion depth d. Analyze a resource-guarded program parametrically in d, derive d ≤ g(n) independently, then substitute g(n) into the monotone cost expression F(n,d). Check that the component instrumentation preserves original costs and that the supplied budget covers every original execution. Compare this composition against standalone recurrence analysis. Carry every premise and its evidence through substitution. See [resource decomposition](REFERENCES.md#hybrid-analysis-and-decomposition).
6. **Hybrid inference.** Instrument selected opaque regions with input/output sizes and tick costs. Hybrid BayesWC models worst-case costs at sampled sizes and uses sampled worst-case observations with static linear constraints to infer candidate bounds. Hybrid BayesPC samples potential coefficients in a space restricted by the static constraints and observations. Compare both against static-only inference and a deterministic fit. Use separate input families for fitting, calibration, and evaluation, including generated high-cost inputs and larger sizes. Publish prior, seeds, sample diagnostics, posterior intervals, and held-out exceedances. See [Hybrid AARA and the thesis](REFERENCES.md#hybrid-analysis-and-decomposition).

## What would count as evidence?

Report the metric, input domain, bound, assumptions, and evidence for each dependency. A locally replayed arithmetic witness establishes the listed inequalities. A source-level certificate additionally needs coverage of reachable edges, checked translation or an explicit trusted frontend, validated summaries, and an exact checker for the composition rule. Record the version and trusted assumptions of external KoAT results. Preserve posterior estimates as statistical evidence through hybrid composition. A statistically suggested candidate can acquire a static guarantee by independent discharge of all universal obligations.

Evaluate the hypotheses on paired examples and counterexamples in the [roadmap](ROADMAP.md). Record the fraction with replayable bounds, precision against hand-derived bounds in the same units, analysis time, and causes of unknown results. Any measured violation of a claimed universal bound on an in-domain input falsifies that claim.
